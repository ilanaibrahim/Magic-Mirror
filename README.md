# Magic-Mirror
Raspberry pi powered personalized mini mirror for my study table inspired by MagicMirror². 

# Features
1. Current Date
2. Dual Time (Maldives & UK)
3. Weather
4. Words of Affirmation
5. F1 driver information
6. Miffy graphics
7. Muslim Prayer Times

# Project Setup
Python packages:
- pandas
- tkinter
- fastf1

API's used:
- open meteo
